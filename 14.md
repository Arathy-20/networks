# Experiment 14 — OSPF Routing

# First configure all interface IP addresses as in Experiment 12.

## Router 2621
enable
configure terminal
router ospf 1
network 172.16.0.0 0.0.255.255 area 0
end

## Router 2501A
enable
configure terminal
router ospf 1
network 172.16.0.0 0.0.255.255 area 0
end

## Router 2501B
enable
configure terminal

## Router 2501C
enable

show ip ospf neighbor
show ip interface brief
