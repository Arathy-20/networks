# Experiment 12 — Static Routing

## Configure Router 2621
enable
configure terminal
interface fastEthernet 0/0
ip address 172.16.10.1 255.255.255.0
no shutdown
exit

ip route 172.16.20.0 255.255.255.0 172.16.10.2
ip route 172.16.30.0 255.255.255.0 172.16.10.2
ip route 172.16.40.0 255.255.255.0 172.16.10.2
ip route 172.16.50.0 255.255.255.0 172.16.10.2
exit

## Configure Router 2501A
enable
configure terminal
interface ethernet 0
ip address 172.16.10.2 255.255.255.0
no shutdown
exit

interface serial 0
ip address 172.16.20.1 255.255.255.0
no shutdown
exit

ip route 172.16.30.0 255.255.255.0 172.16.20.2
ip route 172.16.40.0 255.255.255.0 172.16.20.2
ip route 172.16.50.0 255.255.255.0 172.16.20.2
exit

## Configure Router 2501B
enable
configure terminal
interface serial 0
ip address 172.16.20.2 255.255.255.0
no shutdown
exit

interface ethernet 0
ip address 172.16.30.1 255.255.255.0
no shutdown
exit

interface serial 1
ip address 172.16.40.1 255.255.255.0
no shutdown
exit

ip route 172.16.10.0 255.255.255.0 172.16.20.1
ip route 172.16.50.0 255.255.255.0 172.16.40.2
exit

## Configure Router 2501C
enable
configure terminal
interface serial 0
ip address 172.16.40.2 255.255.255.0
no shutdown
exit

interface ethernet 0
ip address 172.16.50.1 255.255.255.0
no shutdown

ip route 172.16.10.0 255.255.255.0 172.16.40.1

## Verify
show ip interface brief
