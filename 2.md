# Experiment — HTTP Packet Analysis Using Wireshark

## Steps

1. Open the web browser and clear the browser cache.

2. Open Wireshark.

3. Select the active network interface (Wi-Fi/Ethernet).

4. Click **Start Capturing Packets**.

5. Open the browser and visit an HTTP website.

6. In Wireshark, enter the display filter:
   http

7. Click **Apply / Enter**.

8. Stop capturing:
   Capture → Stop

9. Find the first **HTTP GET** packet and select it.

## From First GET Packet

Expand:
Hypertext Transfer Protocol

(a) Source and Destination IP:
Expand:
Internet Protocol Version 4
→ Source Address
→ Destination Address

(b) Find:
Accept
Accept-Language
Accept-Encoding
Accept-Charset (if present)

(c) Find:
Host
Request URI
User-Agent

URL = Host + Request URI

## From First HTTP Response

Select the corresponding response packet.

(d) Source and Destination IP:
Internet Protocol Version 4
→ Source Address
→ Destination Address

(e) Status Code:
Hypertext Transfer Protocol
→ Status Code

Example:
200 OK

(f) Last Modified:
Hypertext Transfer Protocol
→ Last-Modified

(g) Content Length:
Hypertext Transfer Protocol
→ Content-Length

## Calculate Response Time

(h) Note:

Time of GET packet = T1
Time of corresponding response = T2

Response Time = T2 - T1

## HTTP Version

(i) Select GET packet.

Check the Request Line:

GET / HTTP/1.1

Therefore:
HTTP Version = HTTP/1.1
