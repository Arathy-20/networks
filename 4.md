# Experiment — DNS Packet Analysis Using Wireshark

## Steps

1. Clear the DNS cache.

### Windows
ipconfig /flushdns

### Linux
sudo systemd-resolve --flush-caches

2. Clear the browser cache.

3. Open Wireshark.

4. Select the active network interface (Wi-Fi/Ethernet).

5. Start packet capture.

6. Open the browser and visit the college website.

7. In Wireshark, enter the display filter:
   dns

8. Press Enter / Apply.

9. Stop capturing:
   Capture → Stop

10. Save capture:
    File → Save As

## Find First DNS Query

Look in the Info column for:
Standard query

Select the query packet.

(a) Packet Number:
Check the "No." column.

(b) UDP or TCP:
Expand:
User Datagram Protocol / Transmission Control Protocol

Usually DNS uses UDP.

## Find Corresponding DNS Response

Look for:
Standard query response

Match it with the query using the DNS Transaction ID.

(c) Response Packet Number:
Check the "No." column.

Check whether UDP or TCP is used.

## Query Ports

(d) Expand:
User Datagram Protocol

→ Source Port = Client's temporary/ephemeral port
→ Destination Port = 53

## Response Ports

(e)
→ Source Port = 53
→ Destination Port = Client's temporary/ephemeral port

## DNS Server IP

(f) Select query packet.

Expand:
Internet Protocol Version 4

→ Destination Address = DNS Server IP

## DNS Message ID

(g) Expand:
Domain Name System

→ Transaction ID

Query Transaction ID = ______
Response Transaction ID = ______

Both should be the same.

Purpose:
Used to match a DNS response with its corresponding DNS query.

## DNS Flags

(h) Flag field length:
16 bits (2 bytes)

(i) Query/Response bit:
QR bit

QR = 0 → Query
QR = 1 → Response

(j) Response-related bits include:

AA → Authoritative Answer
RA → Recursion Available
RCODE → Response Code

Also inspect the complete Flags section in Wireshark.

## Records in DNS Query

(k) Expand:
Domain Name System

Check:
Questions = ______
Answer RRs = ______
Authority RRs = ______
Additional RRs = ______

Usually a basic query has:
Questions = 1
Answers = 0

## Records in DNS Response

(l) Select corresponding response.

Expand:
Domain Name System

Check:
Questions = ______
Answer RRs = ______
Authority RRs = ______
Additional RRs = ______

## Quick Verification

Query:
Client → DNS Server
Destination Port = 53
QR = 0

Response:
DNS Server → Client
Source Port = 53
QR = 1

Query Transaction ID = Response Transaction ID
